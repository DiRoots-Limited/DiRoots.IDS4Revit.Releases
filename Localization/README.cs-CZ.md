IDS4Revit je plugin pro Autodesk Revit, který zjednodušuje práci se soubory IDS. Uživatelům Revitu usnadňuje splnění požadavků specifikace Information Delivery Specification (IDS).

### Hlavní funkce
- Čtení souborů IDS.
- Kontrola a ověření modelu Revit podle IDS (např. ověření entit a vlastností požadovaných souborem IDS přímo v Revitu).
- Mapování parametrů Revitu na vlastnosti IFC.
- Exportér IFC založený na IDS se zaměřením na splnění požadavků IDS.

### Další funkce
- Ukládání a sdílení konfigurací profilů.

### Podporované verze Revitu
2022, 2023, 2024, 2025 a 2026.
