IDS4Revit è un plugin per Autodesk Revit che semplifica il lavoro con i file IDS. Consente agli utenti di Revit di rispettare facilmente l'Information Delivery Specification (IDS).

### Funzionalità principali
- Lettura dei file IDS.
- Ispezione e convalida del modello Revit rispetto all'IDS (ad es. verifica in Revit delle entità e proprietà richieste dal file IDS).
- Associazione dei parametri Revit alle proprietà IFC.
- Esportatore IFC basato su IDS e incentrato sul rispetto dei requisiti IDS.

### Altre funzionalità
- Salvataggio e condivisione delle configurazioni dei profili.

### Versioni di Revit supportate
2022, 2023, 2024, 2025 e 2026.
