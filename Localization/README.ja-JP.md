IDS ファイルの操作を簡素化し、IDS に照らしたモデル検証と IDS に基づく IFC エクスポートの効率化を実現します。

IDS4Revit は、IDS ファイルの操作を簡素化する Autodesk Revit プラグインです。Revit ユーザーが情報伝達仕様（IDS）に容易に準拠できるよう支援します。

### 主な機能
- IDS ファイルの読み込み。
- IDS に照らした Revit モデルの検査と検証（例：IDS ファイルで要求されるエンティティとプロパティを Revit 内で確認）。
- Revit パラメータを IFC プロパティにマッピング。
- IDS 要件への準拠に重点を置いた IDS ベースの IFC エクスポーター。

### その他の機能
- プロファイル設定の保存と共有。

### 対応する Revit バージョン
2022、2023、2024、2025、2026。
