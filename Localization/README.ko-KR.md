IDS4Revit는 IDS 파일 작업을 간소화하는 Autodesk Revit 플러그인입니다. Revit 사용자가 정보 전달 사양(IDS)을 쉽게 준수할 수 있도록 지원합니다.

### 주요 기능
- IDS 파일 읽기.
- IDS에 따른 Revit 모델 검사 및 검증(예: IDS 파일에서 요구하는 엔티티와 속성을 Revit 내에서 확인).
- Revit 매개변수를 IFC 속성에 매핑.
- IDS 요구 사항 준수에 중점을 둔 IDS 기반 IFC 내보내기.

### 기타 기능
- 프로필 구성 저장 및 공유.

### 지원되는 Revit 버전
2022, 2023, 2024, 2025 및 2026.
