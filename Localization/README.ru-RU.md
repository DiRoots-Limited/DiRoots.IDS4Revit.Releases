IDS4Revit — это плагин для Autodesk Revit, который упрощает работу с файлами IDS. Он помогает пользователям Revit выполнять требования спецификации доставки информации (IDS).

### Основные возможности
- Чтение файлов IDS.
- Проверка и валидация модели Revit по IDS (например, проверка в Revit сущностей и свойств, требуемых файлом IDS).
- Сопоставление параметров Revit со свойствами IFC.
- Экспортер IFC на основе IDS, ориентированный на выполнение требований IDS.

### Другие возможности
- Сохранение и совместное использование конфигураций профилей.

### Поддерживаемые версии Revit
2022, 2023, 2024, 2025 и 2026.
