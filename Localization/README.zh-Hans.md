IDS4Revit 是一款可简化 IDS 文件使用的 Autodesk Revit 插件，使 Revit 用户能够轻松遵循信息交付规范（IDS）。

### 主要功能
- 读取 IDS 文件。
- 根据 IDS 检查并验证 Revit 模型（例如，在 Revit 中检查 IDS 文件要求的实体和属性）。
- 将 Revit 参数映射到 IFC 属性。
- 基于 IDS 的 IFC 导出器，专注于满足 IDS 要求。

### 其他功能
- 保存并共享配置文件设置。

### 支持的 Revit 版本
2022、2023、2024、2025 和 2026。
