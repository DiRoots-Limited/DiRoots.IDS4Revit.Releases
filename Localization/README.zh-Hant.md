簡化 IDS 檔案的使用，可依據 IDS 驗證模型，並最佳化以 IDS 為基礎的 IFC 匯出流程。

IDS4Revit 是一款可簡化 IDS 檔案使用的 Autodesk Revit 外掛程式，讓 Revit 使用者能輕鬆遵循資訊交付規範（IDS）。

### 主要功能
- 讀取 IDS 檔案。
- 依據 IDS 檢查並驗證 Revit 模型（例如，在 Revit 中檢查 IDS 檔案要求的實體和屬性）。
- 將 Revit 參數對應至 IFC 屬性。
- 以 IDS 為基礎的 IFC 匯出器，著重於符合 IDS 要求。

### 其他功能
- 儲存並共用設定檔組態。

### 支援的 Revit 版本
2022、2023、2024、2025 和 2026。
